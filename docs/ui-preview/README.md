# UI preview spec (v7)

Design deliverables from the design thread, kept next to the code.
- `aice-ui-preview.html`: the clickable preview.
- `ui-strings-and-rules.json`: strings (ID, EN, ZH) and rules.
- `guideline-audit.md`: audit against the Bigma guidebook and web rules.

Not all preview wording is used word for word in the Flutter app. The app keeps its own Indonesian source text and the EN and ZH tables in `prototype/lib/l10n/`.
